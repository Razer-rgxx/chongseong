# 영지(가제)

낮에는 영지를 짓고 사람을 뽑고, 밤에는 영주가 직접 칼을 들고 성벽 위의 사람들과 함께 습격을 막는 PC 영지 디펜스. 7일째 밤의 우두머리를 넘기면 그 땅을 지킨다.

- 엔진: Godot 4.6 (GDScript)
- 기획: [docs/GDD.md](docs/GDD.md)
- Claude Code 작업 지침: [CLAUDE.md](CLAUDE.md)
- HTML 시연판: [prototype/yeongji_pc.html](prototype/yeongji_pc.html) (브라우저로 열면 바로 플레이, ` 키로 관리 패널)
- 에셋: 사람이 만든 CC0 에셋만 쓴다 (KayKit 우선)

이 저장소는 이전 기획 「총성」에서 이어진다. 옛 기획은 git 기록에 남아 있다.
