# 인계서: 총성(銃城) → Claude Code

작성 2026-11-05. 이 저장소를 처음 여는 Claude Code가 읽는 문서다. 기획 세부는 [docs/GDD.md](GDD.md), 작업 규칙은 [CLAUDE.md](../CLAUDE.md)가 기준이고, 이 문서는 지금까지 정한 것과 첫 작업을 정리한다. 셋이 서로 어긋나면 GDD.md와 CLAUDE.md를 따르고, 어긋난 곳을 정리에 적는다.

## 1. 한 줄 요약

싸우는 도중에 성을 짓고 부수는 실시간 1:1 판타지 FPS. 설계함에서 뽑은 설계도로 성을 쌓고, 상대 성의 심장석을 먼저 부수면 라운드를 이긴다. 3판 2선승.

## 2. 사용자

- 1인 개발자. Godot 4.6과 GDScript를 쓴다. 한국어로, 짧게 설명한다.
- 좋아하는 재미: 간단한 규칙에서 나오는 짧은 심리전, 발로란트 경쟁전, 마인크래프트 PvP와 건축.
- AI 생성 에셋(그림, 모델, 음악)은 쓰지 않는다. 사람이 만든 CC0 에셋만 쓴다.
- 일은 폰에서 Claude Code에 맡기고, 플레이 테스트와 손맛 조정은 PC의 Godot에서 직접 한다.

## 5. 첫 작업: GDD "다음 단계" 1번

혼자 움직이는 1인칭 이동과 조준점 칸 짓기 (윤곽 예고, 취소 포함). 이 단계에서는 봇, 총, 설계함을 만들지 않는다.

**만들 것**
- project.godot (Godot 4.6). CLAUDE.md의 충돌 레이어 8개를 이름과 함께 등록한다.
- 입력: 이동 WASD, 시점 마우스, 점프 Space, 짓기 오른쪽 클릭과 G, 설계도 바꾸기 휠과 R. 쏘기(왼쪽 클릭)와 설계함 고르기(1, 2, 3)는 이름만 등록해 둔다.
- `scripts/core/grid.gd`: 칸 좌표(Vector2i)와 월드 좌표 변환. 1칸 = 2m, 13 × 17칸.
- 결투장: 바닥, 가장자리 벽, 중립 돌벽 6개 자리, 양 진영 심장석 자리. 모두 기본 도형으로 채운다.
- 1인칭 컨트롤러: CharacterBody3D, 이동 6.5m/s, 짓는 중 45%. 수치는 리소스로 뺀다.
- 조준점이 가리키는 바닥 칸에 테두리를 표시한다. 지을 수 있으면 진영 색, 없으면 회색.
- `BlueprintData` 리소스와 `data/blueprints/palisade.tres`(목책), `stonewall.tres`(돌벽).
- 짓기: 0.5초 시전 동안 반투명 윤곽을 보이고, 다시 누르면 비용 없이 취소, 끝나면 구조물을 세운다(structure 레이어).
- 석재: 시작 4, 4초마다 1, 최대 12. 짓기에 비용을 쓴다. 화면 구석에 숫자로 표시한다.

**완료 조건** (사용자가 PC에서 확인)
1. 실행하면 결투장 안을 걸어 다니고 점프할 수 있다.
2. 바닥을 보면 칸 테두리가 따라온다.
3. 오른쪽 클릭하면 0.5초 윤곽 뒤 목책이 서고 석재가 1 줄어든다.
4. 시전 중에 다시 누르면 취소되고 석재는 그대로다.
5. 사람이 선 칸, 이미 지은 칸, 심장석 칸에는 지어지지 않는다.
6. 휠이나 R로 목책과 돌벽을 바꿀 수 있고, 돌벽은 석재 2가 든다.

끝나면 GDD의 1번 줄을 `- [x]`로 바꾸고 커밋한 뒤, 만든 것과 PC에서 확인할 것을 한국어로 짧게 정리하고 멈춘다.
