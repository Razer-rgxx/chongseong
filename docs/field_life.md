# 30~34단계 설계서: 점프, 어려운 무덤, 우두머리, 오픈월드 한정 검, 떠도는 사람 영입

2026-11-19 밤 사용자가 정함(들판을 해 보고): "점프 추가, 무덤도 너무 쉬움, 오픈월드도 별로 할 게 없어".
고른 것: 점프는 **걸어 다니는 점프만**(싸움 규칙은 안 바뀜). 들판에는 **곳마다 우두머리**, **가끔 사람이 나타나고 마을로 영입**, **오픈월드 한정 검**. 무덤은 더 어렵게.

공통 규칙은 docs/outside.md 맨 위와 같다: 어두운 사실풍, AI 에셋 없음, 세계에 글자 없음(피해 숫자만), 말은 `Band`, 곳 이름은 `AreaTitle`, 창은 `UiKit`, 판 밖의 랜덤은 `Meta.rng`, 규칙의 랜덤은 `Rules.rng`, 꾸밈 랜덤은 화면 쪽. 종소리·올라가는 삐 소리·위로 쓸어 올리는 소리 없음. 옛 저장은 기본값으로 읽힌다. 아래에서 정하지 않은 것은 가장 단순하게 정하고 이 문서 "정한 것"에 적는다.

---

## 30단계: 점프(걸어 다니는 점프)

- **키.** 새 행동 `jump` = Space. 지금 베기(`attack`)의 예비 키 Space는 뺀다. 설정 창(`GameSettings.ACTIONS`)에 "점프"를 더한다.
- **규칙.** `LordInput.jump`(누른 틱), `LordState`에 공중 시간. 땅에 있을 때만 뛴다(두 번 뛰기 없음). 구르기·뽑기·좌클릭 동작 중에는 안 뛴다. 공중에서는 걷던 대로 움직이고 좌클릭은 안 나간다. 수치는 `data/lord.tres`(`jump_time` 0.55초, `jump_height` 1.1m).
- **싸움 규칙은 그대로.** 공중이어도 맞고, 피하는 효과는 없다. 결투(`step_duel`, 온라인 바이트)는 점프를 쓰지 않는다(입력에 넣지 않는다, 결정성과 바이트 모양 그대로).
- **넘기.** 막힘마다 높이가 있다. 낮은 막힘(높이 ≤ `JUMP_CLEAR` 1.0m: 울타리, 무너진 낮은 벽, 쓰러진 통나무, 작은 바위, 우물 둘레 같은 것)은 **공중에 있는 동안** 지나갈 수 있다. 내려앉을 때 낮은 막힘 안이면 밖으로 밀어낸다. 높은 막힘(집 벽, 성벽, 벼랑, 무덤 벽 1.5m)은 못 넘는다. 들판(`FieldLayout`/`FieldBuilder`), 마을(`lobby.gd`의 `_rects/_circles`), 무덤(`CryptLayout`)에 낮은 막힘 표를 따로 둔다. 밀어내기는 장면마다 따로 있는 `_push_out`을 정적 함수 하나(예: `Blockers.push_out(p, rects, circles, low_rects, low_circles, airborne)`)로 모아 테스트할 수 있게 한다.
- **그림.** 영주가 포물선으로 뜬다(`LordView`가 높이를 더한다). 자세는 코드로: 웅크렸다 → 다리 접고 → 내려앉으며 무릎 굽힘. Mixamo 동작 파일 이름에 `hop`이 있으면 그것을 쓴다(`jump`는 이미 도약 내려찍기 낱말이라 쓰지 않는다). 내려앉을 때 작은 흙먼지와 발소리(코드 소리).

## 31단계: 무덤을 어렵게

- 무리 세기 5~7구역 → **8~10구역**(구역 표 끝 10). 방마다 적 +2마리. 방마다 **정예** 하나(언덕의 정예처럼 금빛 고리, 체력 4배·피해 1.5배).
- 서쪽 끝 선택 방(r5)은 가장 세다(10구역, 적 +3).
- 무덤 주인: 체력 800 → **2000**, 피해 16 → **24**, 부르기 망령 2 → **4마리**, 체력 50%와 25%에서 두 번 부른다. 빨라짐 ×1.2 → ×1.3.
- 보상은 그대로 두되 큰 관에 **오픈월드 한정 검 하나**(33단계, 처음 열 때만).
- 테스트 기대값을 고친다.

## 32단계: 곳마다 우두머리

- 곳 여덟에 우두머리 하나씩(옛 싸움터는 이미 무덤 기사가 있다): 무너진 망루, 검은 숲 가장자리, 언덕 발치, 무너진 성채, 안개 늪, 버려진 채석장, 불탄 마을, 까마귀 고개.
- 우두머리는 **이미 있는 적의 큰 판**이다(`data/enemies/`에 한 줄씩, 이름·체력·피해·크기·색). 행동은 그 종류의 `Foes` 행동을 그대로 쓰고, 기사형은 `Foes._knight`를 쓴다. 예(이름은 다듬어도 된다): 망루의 궁수장(활잡이, 연사), 검은 숲의 늑대왕(늑대), 발치의 거인(거인), 성채의 방패대장(방패병), 늪의 부르는 자(부르는 자, 더 많이 부름), 채석장 감독(돌격병), 불탄 거인(거인, 그을린 색), 고개의 기사(무덤 기사형).
- 규칙: 들판 보스(18단계)처럼 깨어남 8칸·놓아줌 14칸·돌아가면 체력이 참. 여럿이 되도록 일반화한다(예: `Rules.chiefs` id → 상태). 화면 아래 체력 막대(`LobbyHud.set_boss`)는 깨어 있는 우두머리의 것. 이름 글자를 지금보다 크고 또렷하게.
- 판이 끝날 때(`record_run`) 다시 선다. 들판 낮밤(29단계)의 밤에는 무리처럼 세진다(피해 ×1.25).
- 보상: 처음 쓰러뜨리면 조각 50과 **그 곳의 오픈월드 한정 검**, 그다음부터 조각 15. 저장 `Meta.chiefs_first`·`chiefs_down`(이번 판).

## 33단계: 오픈월드 한정 검

- 새 검 **10자루**(`data/swords/301.tres`~`310.tres`, `SwordData.field_only = true`). 언덕의 뽑기·대장장이·상인 등 **어디서도 뽑히지 않는다**(뽑기 후보에서 뺀다). 등급은 전설 6·신화 3·초월 1. 이름·형태·각인·공격 방식(이미 있는 150가지 중)은 어두운 이름으로 짓는다. `scripts/debug/build_attacks.gd`가 001~300만 다루게 하고 301~310의 `attack`은 손으로 정해 둔다(도구를 다시 돌려도 덮어쓰지 않게).
- 얻는 곳: 우두머리 8(곳마다 하나), 무덤 큰 관(처음), 영입한 몰락한 기사(34단계)가 주는 것 하나 = 10.
- 얻으면 `Meta.found`(도감)에 들어가고, 전설 이상이라 **검집에 넣을 수 있다**. 들판 북문 검 고르기·수련장 검 걸이 목록에도 나온다. 도감 진열대에는 "들판의 검" 줄을 따로 둔다.
- 검 표 크기(300)를 보는 테스트는 310과 field_only를 알게 고친다.

- 각인 수는 언덕의 검과 같다(전설 1, 신화·초월 2). 공격 방식은 제 등급대의 것 중 갈고리가 없는 것을 골랐다(갈고리 검 수는 그대로). 뽑기 손잡이·낮·밤 끝을 보는 각인(가벼운 손, 행운, 새벽)은 들판에서 쓸모가 없어 뺐다.
- 초월은 언덕의 초월처럼 고유 능력이 있다: 「꺾인 깃발」 = 이 밤 쓰러뜨린 적 하나마다 받는 피해 -2%, 최대 40%(`Powers.lord_damage`, 수치는 `PowerTable.uniques`, `Powers.READY`에 넣었다). 들판에서는 밤이 끝나지 않으니 들판에 있는 동안 쌓인다.
- 뽑기 후보에서 빼는 곳은 `GameData.swords_by_grade` 한 곳이다(`field_only`면 넣지 않고 `GameData.field_swords`에 따로 둔다). 언덕의 뽑기는 `Rules.pick_sword(등급)`으로 묶었다(테스트가 6000번 돌린다). 대장장이·상인·낮 사건은 검을 주지 않고, 「이름을 잃은 검」이 도감을 다 채울 때(`main.gd`의 dex_all)도 언덕의 검만 채운다. 관리 콘솔(`SwordConsole`)은 관리용이라 그대로 다 준다.
- `build_attacks.gd`는 id 300까지만 다룬다(`LAST_HILL_SWORD`, 파일에 `field_only = true`가 있어도 건너뜀). 다시 돌려 보니 001~300과 방식 150가지가 한 글자도 바뀌지 않았다.
- 검집·북문·검 걸이는 이미 "찾아 본 검"(`Meta.found`)을 보므로 얻는 순간 나온다(대장간 안내 글만 "찾아 본 전설 이상"으로 고쳤다). 도감 진열대 창 맨 아래에 "들판의 검 n / 10 · 언덕에서는 뽑히지 않는다" 줄을 두고 찾은 이름은 제 등급 빛으로 쓴다. 마을의 진열대 모형에도 찾은 한정 검이 한 자루 더 선다. 도감 머리의 "도감 n / 310"은 한정 검을 센다.

## 34단계: 떠도는 사람과 영입

- 다섯 사람: **약초꾼, 떠돌이 대장장이, 늙은 사냥꾼, 길 잃은 순례자, 몰락한 기사.**
- 들판 새벽마다(29단계 `field_dawn`, 그리고 들판에 들어올 때 아무도 없으면) 아직 영입하지 않은 사람 중 하나가 정해진 후보 자리(`FieldLayout.WANDERER_SPOTS`, 길·곳 가장자리 8곳 정도) 중 한 곳에 선다(`Meta.rng`). 한 번에 한 사람.
- E로 말을 건다(Band에 한두 줄). 영입 조건 하나씩: 약초꾼 = 조각 40을 낸다, 사냥꾼 = 그 근처 무리 하나를 쓰러뜨린다, 순례자 = 비석 다섯을 읽었다, 대장장이 = 오픈월드 한정 검 하나를 가졌다, 기사 = 우두머리 셋을 쓰러뜨렸다. 조건이 맞으면 다시 E로 영입한다.
- 영입하면 마을에 선다(`Meta.recruits`, 자리는 마을 빈 곳, 주민처럼 E로 한 줄 말). 효과(작게, 이미 있는 계산에 곱한다): 약초꾼 = 판 시작·들판 체력 +10, 대장장이 = 망치질 값 -20%, 사냥꾼 = 들판 무리 전멸 조각 +50%, 순례자 = 성소 축복 값 -20%, 기사 = 영입할 때 오픈월드 한정 검 하나를 준다.
- 모양: 마을 주민 모양(`VillageProps`의 주민)을 빌려 옷 색만 다르게. 세계에 글자 없음.
- 저장: `Meta.recruits`, 지금 선 사람과 자리(`wanderer`, `wanderer_at`). 옛 저장은 비어 있다.
