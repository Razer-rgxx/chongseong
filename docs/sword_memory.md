# 검의 기억과 검의 이름 (2026-11-26)

사용자의 스케치: 파란 모양은 룬(칼날에 새긴 각진 무늬: 마름모 테두리, V 표시), 붉은·보랏빛 모양은 보석(깎은 돌). 검이 쓰일수록 칼날에 룬이 떠오르고 보석 자리가 열린다.
수치는 모두 `data/runes.tres`(`RuneTable`, scripts/core/data/rune_table.gd)다. 규칙은 `Meta`(scripts/core/meta.gd "검의 기억" 절)와 `Powers.cv`, 그림은 `CarveOverlay`(scripts/world/carve_overlay.gd).

## 정한 것 (물어보지 않고 가장 단순한 쪽)

- **기억 = 그 검 번호로 벤 적 수.** 예전 검의 기록(`Meta.sword_log[id].k`)이 이미 언덕·들판·무덤·미래·과거의 처치를 검 번호로 센다(`log_kill`). 새로 세지 않고 그것을 기억으로 쓴다. 옛 "기억 단계"(1000/2500/… 이름과 피해 +2%)는 그대로 둔다.
- **쓰임 센 것** `Meta.sword_memory[id]`: 큰 베기 `big`, 밤 `night`, 낮 `day`, 우두머리 `boss`, 정예 `elite`, 돌진 `dash`, 맞음 `hurt`, 처치 연쇄 5 이상 `chain`. `Rules`가 처치·돌진·맞음 자리에서 세어 Meta에 적는다(결투는 안 센다). "밤"은 언덕의 밤, 들판 시계의 밤, 시계가 없는 곳(무덤·미래·과거)은 늘 밤.
- **룬 자리**: 벤 적 100 · 400 · 1000에 하나씩(`slot_kills`). 열릴 때(`log_kill`, 관리 `기억`) 룬이 저절로 새겨진다.
- **룬 고르기(결정적)**: 아직 안 가진 룬 중 그 룬의 쓰임(counter)을 가장 많이 센 것. 같으면 표 순서(`rune_order`), 쓰임이 없으면 표 순서. 새긴 룬은 저장된다(나중에 쓰임이 바뀌어도 안 바뀐다).
- **보석 자리**: 룬 0개 → 0, 1개 → 1, 2개 이상 → 2(`sockets`). 보석은 주머니(`gem_bag`)에서 박고, 빼면 조각을 내고 주머니로 돌아온다(사라지지 않는다).
- **보너스는 쥔 검에만** 붙는다. 수치는 `Meta.carve_of(id)`(화면 거울)에서 `Powers.cv(키)`로 읽고, `Sword`의 내구는 만들 때 곱한다. 결투(능력 끔)에서는 0. 룬·보석은 같은 키끼리 더해진다.
- `state_hash`: 규칙 상태는 `Rules.carve_shard`(호박·연쇄의 룬이 모은 조각)만 늘어서 해시에 넣었다. 룬·보석은 Meta의 입력이라 규칙 상태가 아니다. 같은 시드·입력·Meta면 결과가 같다(테스트).
- **조각(호박·연쇄의 룬)**은 판(언덕)이 끝날 때 `Meta.run_shards`의 `carve`로 센다. 들판·무덤·미래·과거의 처치 조각(`field_kill`)에는 안 붙는다(가장 단순한 쪽).
- 치명타(예리의 룬, 청금석)는 `Powers.strike`에서 `Rules.rng`로 굴려 피해 ×1.5(`crit_mult`). 확률이 0이면 굴리지 않아서 예전 결과와 같다.

## 룬 8종 (자동, 쓰임으로 고른다)

| 룬 | 쓰임(센 것) | 효과 |
| --- | --- | --- |
| 예리의 룬 | 큰 베기로 벤 적 | 치명타 확률 +4% |
| 밤의 룬 | 밤에 벤 적 | 밤에 피해 +5% |
| 낮의 룬 | 낮에 벤 적 | 내구 +6% |
| 사냥의 룬 | 우두머리 처치 | 우두머리에게 피해 +8% |
| 바람의 룬 | 돌진 횟수 | 휘두르는 속도 +4% |
| 불굴의 룬 | 맞은 횟수 | 받는 피해 -4% |
| 연쇄의 룬 | 연쇄 5 이상 처치 | 벨 때마다 조각 +0.05 |
| 정예의 룬 | 정예 처치 | 밀어내기 +8% |

## 보석 6종 (단계 1~3: 거친 · 고운 · 흠 없는)

| 보석 | 효과(1/2/3단계) |
| --- | --- |
| 홍옥 | 피해 +3/6/10% |
| 자수정 | 내구 +8/16/30% |
| 청금석 | 치명타 확률 +3/6/10% |
| 호박 | 벨 때마다 조각 +0.05/0.10/0.20 |
| 흑요석 | 밀어내기 +10/20/35% |
| 월장석 | 각인 세기 +5/10/18%(`Powers.ins`·`held`) |

얻는 법: 우두머리(들판 무덤 기사, 곳마다 우두머리, 무덤 주인 …)를 쓰러뜨리면 35%(`drop_boss`, 높은 단계가 더 나옴), 유품 상자·무덤 관·미래 함·과거 함(`field_open`, `crypt_open`)을 열면 12%(`drop_cache`). 대장간에서 조각으로 살 수도 있다(60 / 180 / 500).
박는 곳: 마을 대장간 E → "보석 박기" 탭. 룬이 새겨진 검(찾은 것)을 고르고 자리에 박는다. 빼기는 조각 10 / 30 / 80.

## 모양

`SwordModel.carve(룬 목록, 보석 목록)` → `CarveOverlay.apply`. 칼날 길이·너비·칼끝 x만 읽어서 절차 모양과 Blender 모델 모두에 붙는다. `SwordModel.for_sword`(영주가 쥔 검)와 마을 진열, 떨군 검이 저장된 것(`Meta.carvings`, 화면 거울)을 자동으로 얹는다.
- 룬: 칼날 앞뒤에 얇은 푸른 빛 막대로 만든 마름모 테두리·V·마름모+V·겹친 V(룬 번호 mod 4). 룬 하나마다 칼날 위로 한 칸씩.
- 보석: 낮은 분할의 구(깎은 돌 모양). 첫 보석은 칼날 밑동 앞뒤, 둘째는 코등이 양 끝. 종류마다 빛 색(홍옥 붉음, 자수정 보라, 청금석 파랑, 호박 주황, 흑요석 어두운 보라, 월장석 흰 파랑).

## 검의 이름

- 지을 수 있을 때: 룬 3개(벤 적 1000) 이상, 또는 무한 등급(룬 없이도). 대장간 "보석 박기" 탭 아래 입력칸, 최대 12자(`name_max`).
- `Meta.sword_names[id]`에 저장. **원래 이름(`SwordData.display_name`)은 안 바꾼다**(고유 능력이 이름으로 찾기 때문). 화면은 `Meta.shown_name(데이터)`와 `Sword.label()`을 쓴다. 바꾼 곳: 뽑기 알림·부러짐(main), 검 카드·HUD의 검 이름(`Sword.label`, `memory_title`), 도감·진열·검집 목록(lobby_hud), 미래 구역 검 목록(`SwordList`), 결투 HUD의 두 영주 이름 곁(`DuelHud.set_swords`).
- 온라인 결투에서 상대 검의 이름은 내 저장의 것이라 상대가 지은 이름은 안 보인다(입력만 주고받는 락스텝이라 이름을 안 보낸다).
- **글꼴**: 기본 글꼴 던파 연단된 칼날(`DNFForgedBlade-Medium.otf`)이 한글 음절 11172자를 모두 가졌다(fontTools로 확인, 테스트도 본다). 그래서 어떤 한글 이름도 상자(두부)로 안 나온다. 그래도 이름에 쓸 수 있는 글자를 한글 음절·영문·숫자·공백으로 걸러(`Meta.clean_name`) 글꼴에 없는 글자와 BBCode(`[`, `<`)가 못 들어오게 했다. 글꼴을 다시 만들거나 Noto 전체를 넣지 않았다(라이선스상 던파 글꼴은 그대로 두고, Noto 부분 글꼴은 그대로 대체용).

## 길라잡이, 관리 명령

- 길라잡이 두 단계(낯선 사람 뒤, 숨은 미래 단계 앞): "검에 첫 룬 새기기"(조각 15), "보석 박기"(조각 20, 마을 대장간 방향). 옛 저장에서는 새 칸이 없어서 둘 다 처음부터 센다(`legacy_ok` 없음).
- 관리 콘솔(`) `기억 <검번호> <벤 적 수>`(그 검의 벤 적을 그 수로 정하고 룬을 새긴다), `보석 <홍옥|자수정|청금석|호박|흑요석|월장석> <1~3>`(주머니에 하나).
- 시험: 마을에서 `기억 1 1000` → 대장간 E → 보석 박기 탭에서 1번 검(찾은 검만 목록에 든다, 먼저 `재료`처럼 도감에 검이 있어야 함) 고르기 → `보석 홍옥 3`으로 받은 보석을 박고 이름을 짓는다.
