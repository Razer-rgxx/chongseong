# 사이버 검 200자루 (2026-11-25)

낯선 사람이 가져온 시간의 쇠로 만든 총검(銃劍) 200자루. 칼날 밑에 총열, 코등이 뒤에 탄창, 날을 따라 청록 빛 줄. 기존 검 300자루와 사이버 카타나(311)는 그대로이고, 새 검과 새 능력만 더한다. 모든 수치는 첫 값이라 테스트하며 바뀐다.

## 약속
- **번호와 이름표:** 312~511(`CyberSwords.FIRST/LAST`). 사이버 카타나(311)도 사이버 검(`cyber = true`)이지만 오픈월드 한정(`field_only`)이라 언덕 뽑기에는 안 든다. `SwordData`에 `cyber`·`sub_type`·`cyber_powers`가 늘었다. 종류는 번호로 정해진다: `(번호 - 312) % 6`(단검, 카타나, 오니마루, 환도, 중장도, 대검).
- **파일:** `data/swords/312~511.tres`는 `scripts/debug/build_cyber_swords.gd`(시드 20261125)가 쓴다. 다시 돌려도 같은 파일이 나온다. 손으로 고치지 않는다.
- **형태:** 기존 4가지에 맞췄다(새 형태를 만들지 않았다). 단검 → 단검, 카타나 → 세검, 오니마루·환도 → 장검, 중장도·대검 → 대검. 종류마다 다른 것은 모양(휘어짐, 폭, 코등이, 손잡이 길이: `CyberModel.SHAPE`)과 이름뿐이다.
- **등급:** 흔함 34, 귀함 40, 전설 44, 신화 38, 초월 32, 무한 12(언덕 표보다 조금 위쪽). 종류마다 고르게 나누고 무한은 종류마다 둘이다. 각인은 흔함~전설 1개, 신화 이상 2개를 시드로 골랐다("투박함" 빼고).
- **이름:** `종류 + 번호표 + 「별칭」`(예 `카타나 Mk.X 「절단선」`, `환도-13 「유리 왕관」`, `중장도 「폐허의 왕」`). 별칭은 형용사 30 × 명사 30에서 겹치지 않게 뽑고 무한 12자루는 손으로 지었다. 실제 상표 이름은 쓰지 않았고, 기존 311종과 이름이 겹치지 않는다(테스트).
- **공격 방식:** 새로 만들지 않고 같은 등급의 기존 방식(`data/attacks/patterns`)을 돌려 썼다(`build_attacks.gd`는 300 넘는 번호를 건드리지 않는다).

## 새 능력 14가지 (`CyberPowers`, `Powers.C`)
쥔 검의 `cyber_powers`에 이름이 있을 때만 듣는다(결투는 `Powers.off`라 안 듣는다). 랜덤은 안 쓰고 세는 값과 시간으로만 정해진다(`state_hash`에 든다). 수치는 `PowerTable.cyber`, 피해 배수는 등급마다 +12%(무한 ×1.6, `cyber_grade_scale`). 흔함·귀함은 능력 1개, 전설부터 2개, 무한 12자루는 서로 다른 짝이고 다른 등급의 짝과도 겹치지 않는다(테스트).

| 능력 | 하는 일 |
| --- | --- |
| 산탄 | 큰 베기 끝에 앞쪽 부채꼴(5칸, 1.2라디안)로 피해 ×0.9와 밀림 |
| 관통탄 | 큰 베기마다 모든 적을 꿰뚫는 탄(`Rules.projectiles`, 종류 bullet) |
| 과열 | 같은 적을 4번 맞히면 터져 둘레에 피해 ×2와 불 |
| EMP | 큰 베기가 파동을 낸다(4칸): 드론·기계(`EnemyData.future`)는 기절, 나머지는 느려짐 |
| 해킹 | 4번 맞힐 때마다 그 적이 3초 홀려 가까운 적을 친다(보스 제외, 망각의 `confused` 재사용) |
| 글리치 순간베기 | 큰 베기에 7칸 안의 가까운 적 뒤로 순간 이동해 피해 ×2.2(재사용 4초). 사이버 카타나(311)의 능력 |
| 플라즈마 칼날 | 휘두른 길 두 곳에 2초 남는 자리, 닿은 적이 탄다 |
| 탄창 | 4번 휘두를 때마다 탄 한 발 |
| 반동 돌진 | 큰 베기에 탄을 쏘고 반동으로 뒤로 밀려난다(`LordState.push`) |
| 레일 | 큰 베기에 18칸 긴 선을 맞힌다(즉시) |
| 연사 | 작은 베기마다 약한 탄 두 발(0.09초 간격) |
| 오버클럭 | 쓰러뜨릴 때마다 공격 속도 +7%(최대 6번, 4초 지나면 식음) |
| 방벽 | 6명 쓰러뜨릴 때마다 방어막(12, 최대 40) |
| 조준 | 체력 90% 이상인 적에게 피해 ×1.5(등급 배수 적용) |

- 탄은 `Moves.shoot_bullet`이 만든다: 검기(`wave`)의 날아가는 규칙을 그대로 쓰되 큰 베기가 아니고 내구를 안 깎고 휘두르기 소모(바꿔 쥐기, 핏빛 맹세)를 건드리지 않는다. 맞힌 적마다 `Powers.strike`를 거친다.
- **정한 것:** "해킹"의 아군은 새 아군 종류를 만들지 않고 이미 있는 홀림(`confused`)으로 했다. "반동 돌진"은 순간 이동이 아니라 영주의 밀림 속도(`push`)다. "글리치 순간베기"는 막힘 표를 따로 보지 않고 구역 안으로만 자른다(막힘 안에 서면 틱 끝의 밀어내기가 빼낸다). 연사·탄창의 탄은 영주가 보는 쪽으로만 나가고 겨누지 않는다.

## 얻는 길
- **언덕 뽑기:** 낯선 사람 이야기를 마친 뒤(`Meta.rift_open`)부터 뽑을 때마다 25%(`PowerTable.cyber_pull_share`) 확률로 같은 등급의 사이버 검이 나온다(`Rules.pick_pull_sword`, 후보 `GameData.cyber_by_grade`). 그 전, 들판, 결투, 수련장에서는 `rng`를 더 쓰지 않아 예전과 똑같다(테스트). 사이버 검은 언덕의 기본 뽑기 목록(`swords_by_grade`)에 안 든다.
- **미래 구역의 꽂힌 낯선 검 셋:** 한 번 들를 때마다 시작 자리 북쪽에 사이버 검 셋이 꽂혀 있다(`FutureLayout.CYBER_HILTS`, `CyberSwords.roll_future`: 운 4로 등급을 굴려 서로 다른 검 셋). 무엇인지 보이고(`HiltView`가 그 검 모양을 그린다) E로 뽑으면 체력 없이 도감에 오른다(`Meta.note_found`). 정한 것: 뽑기 손맛(창 맞추기)과 체력 값은 쓰지 않고, 검은 손에 들지 않고 도감에만 올린다(마을 검 걸이·검집에서 고른다). 저장하지 않으니 다시 들르면 새로 선다.
- **관리자:** 콘솔 `검 <번호>`(예 `검 349`)나 검 이름 일부로 어느 검이든 쥘 수 있다.

## 모양
- **코드 모양(`CyberModel`, 200자루 모두):** 종류마다 칼날 휘어짐·폭·칼끝·코등이(막대, 둥근 판과 청록 고리, 뿔, 꽃잎, 블록, 날개)·손잡이 길이가 다르고, 총열(대검은 둘)과 청록 총구 고리, 탄창 상자, 날 쪽 청록 빛 줄, 전설부터 방열창, 무한과 큰 칼에는 등의 레일. 재질은 등급이 오를수록 총기처럼 검어진다. 빛은 늘 청록이고 등급 색은 자루끝 장식에만 쓴다. 초월 이상은 청록 빛 알갱이.
- **무한 12자루는 Blender(`tools/blender/make_cyber_swords.py`):** 사이버 카타나(311)의 재질·도구(`make_swords.py`)를 빌려 `assets/swords/<번호>.glb`를 만든다(질감 512, 311은 1K). 이 기계에는 Blender가 없어서 pip의 `bpy` 모듈(5.3)로 돌렸다(`python tools/blender/make_cyber_swords.py [번호…]`). 파일이 없으면 코드 모양이 대신한다. 게임에서는 빛을 청록으로 고정하고(`CyberModel.glow_boost`) 손잡이·칼끝을 종류에 맞춘다.
- **효과(`PowerFx`, `MoveFx`):** 총구 불꽃(청록 공과 십자 빛)과 탄 줄, 산탄 부채꼴, 레일 빔, 순간베기 고리와 선, 플라즈마 자리 빛 판. 탄은 가는 청록 빛(`MoveFx`의 bullet). 총성은 짧고 날카로운 딱(`Sfx` crack)이고 높낮이만 흔든다. 올라가는 소리와 종소리는 없다.

## 테스트
`tests/cyber_tests.gd`: 개수와 등급 분포, 종류·형태·능력 칸, 무한 조합 유일, 사이버 능력 14가지 각각(결과와 재사용 대기, 시간), 311, 같은 시드 상태 해시, 뽑기 문(닫힘·열림·25%·들판), 미래 꽂힌 검, 저장. 기존 테스트의 311종·300종 가정과 유니크 일치 검사는 사이버 검을 빼도록 고쳤다.
