# 1대1 결투 (21·22단계 설계서)

2026-11-19 사용자가 정함(GDD 2.15): 모르는 사람과 매칭(GD-Sync 무료판), 웹판 없음, 서로 검으로 벤다, 곳은 언덕 싸움터, 각자 **검집의 검**을 들고 간다. 21단계는 규칙과 같은 PC 시험, 22단계는 온라인.

사용자가 자리에 없을 때 쓴 설계다. 아래 "가장 단순하게 정한 것"은 사용자가 바꿀 수 있다(바꾸기 전에는 이대로).

---

## 21단계: 결투 규칙과 같은 PC 시험

### 규칙

- **영주 둘.** `Rules.lords: Array`(0 = 나/방장, 1 = 상대). 지금의 `rules.lord`는 `lords[0]`을 가리켜 옛 코드가 그대로 돈다. 결투 모드(`Rules.duel = true`, `start_duel(sword_a, sword_b)`)에서는 낮밤·구역·뽑기·적이 없다.
- **틱.** `step_duel(input_a: LordInput, input_b: LordInput)`. 30Hz, 랜덤은 `Rules.rng` 하나, `state_hash`에 두 영주가 다 들어간다. 같은 시드·같은 입력이면 같은 결과(22단계가 이것에 기댄다).
- **맞히기.** `Moves`가 결투에서는 상대 영주를 맞힌다(판정 모양·늦게 터지는 것·날아가는 것·반격 자세 그대로). 구르기 무적, 넉백, 히트스톱은 적을 칠 때와 같다. 갈고리 검이면 우클릭 갈고리를 상대에게 건다.
- **검.** 각자 검집의 검 하나(검집이 비었으면 맨손). 결투에서는 부러지지 않는다. **각인과 고유 능력은 결투에서 끈다**(가장 단순하게 정한 것: 적을 상대로 만든 것이라 사람에게 그대로 쓰면 깨지는 것이 많다). 공격 방식(좌클릭 150가지)과 속성 피해는 켠다.
- **체력과 판.** 수치는 `data/duel.tres`(DuelData): 체력 300(둘 다 같다), 한 판 90초, 3판 2선승, 판 사이 3초. 시간이 다 되면 남은 체력 비율이 높은 쪽이 이긴다(같으면 비김, 그 판은 다시 하지 않는다).
- **곳.** 언덕 싸움터(34 × 22칸, 장애물 없음). 시작 자리는 가운데에서 좌우로 6칸씩, 서로 마주 본다.
- **보상.** 없다(가장 단순하게 정한 것). 결투 기록(이김·짐)만 `Meta`에 센다.
- **22단계 준비.** `LordInput`을 바이트로 바꾸고 되돌리는 함수(`to_bytes`/`from_bytes`)를 넣고 테스트한다.

### 같은 PC 시험

- **들어가기.** 마을 광장에 결투 말뚝 하나(기본 도형). E → 창: "같은 PC로 겨루기"(21단계), "모르는 사람과 겨루기"(22단계까지 흐리게). 1P와 2P가 차례로 검집에서 검을 고른다.
- **입력.** 1P는 키보드와 마우스(지금 그대로), 2P는 게임패드 0번(왼 스틱 이동, 오른 스틱 겨눔, RT 좌클릭, LT 갈고리, A 구르기). 게임패드가 없으면 2P는 가만히 서 있는다(시험용 허수아비가 된다).
- **카메라.** 같은 PC에서는 둘을 함께 담는 쿼터뷰 하나(둘 사이 가운데를 보고, 멀어지면 물러난다). 3인칭 화면 나누기는 하지 않는다(온라인에서는 각자 3인칭).
- **화면.** 영주 둘은 `LordView` 둘(2P는 망토 색을 어둡게 바꿔 구별). 위 가운데에 두 체력 막대와 판 점수(UI라 글자 괜찮다), 판이 끝나면 `Band`로 "1P 이김" 같은 한 줄, 다 끝나면 결과 창(UiKit) → 마을로. 세계에 글자 없음.
- **장면.** `scenes/duel/duel.tscn`, `scripts/duel/duel.gd`. 땅·하늘은 `HillBuilder`.

## 22단계: 온라인 매칭 (GD-Sync)

- 사용자가 GD-Sync에 가입해 키를 받아야 한다(키는 git에 올리지 않는다: `user://` 또는 무시되는 설정 파일).
- 방식은 22단계를 시작할 때 고른다. 후보: 방장이 규칙을 돌리고 상대는 입력만 보내 방장이 상태를 돌려준다(쉬움, 상대는 늦게 느낀다) / 입력만 주고받는 락스텝에 입력 지연 몇 틱(규칙이 결정적이라 가능, 둘 다 똑같이 늦다). GD-Sync 무료판의 하루 200MB 안에 들게 입력만 보내는 쪽을 먼저 본다.
- 매칭: GD-Sync 공개 방 찾기 → 없으면 방 만들고 기다림. 각자 3인칭.
