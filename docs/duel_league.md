# 결투 리그 (2026-11-26, 기능팀)

사용자 요청: 발로란트 같은 티어가 있는 결투 리그. 사용자가 자리에 없을 때 쓴 설계라 애매한 곳은 가장 단순하게 정했다(아래 "정한 것"). 수치는 모두 `data/league.tres`(LeagueData) 한 곳.

## 규칙

- **티어(낮은 쪽부터):** 녹쇠, 청동, 은, 금, 백금, 금강, 승천, 불멸 — 각각 1/2/3단계. 맨 위는 **언덕의 검**: 불멸 3이면서 시즌 순위표 위쪽 100명인 사람의 표시. 걸음(step) = 티어 × 3 + (단계 − 1), 0 = 녹쇠 1, 23 = 불멸 3. 24는 걸음이 아니라 표시(`League.SWORD_STEP`).
- **RR:** 단계마다 0~100. 100에 닿으면 승급(넘친 만큼 남는다), 0 밑이면 강등(앞 단계 `100 + RR`). 이기면 +18~28, 지면 −12~22. 불멸 3에서는 RR이 100을 넘어 쌓이고(승급 없음) 순위표 점수가 된다. 녹쇠 1은 더 안 내려간다.
- **숨은 MMR(Elo 꼴):** 처음 1000. 상대의 MMR을 모르므로(아래) 상대를 "내 걸음의 기준값"(`mmr_base + 걸음 × mmr_per_step`)으로 어림해 판마다 K=32만큼 움직인다. 증감량은 `기본(+23/−17) ± (MMR − 기준값) × 0.06`을 한계 안으로 자른 값 → 걸음보다 MMR이 높으면 더 받고 덜 깎인다.
- **강등 보호:** RR이 0 밑으로 내려갈 판이면 한 번은 0에 머문다(`shield`). 이기면 다시 찬다. 강등된 뒤에도 찬다.
- **배치:** 처음 5판은 RR이 없고 MMR만 움직인다(K=60, 상대는 시작값 어림). 5판째에 `(MMR − 850) / 40`의 걸음으로 시작하되 **금 1(걸음 9)을 넘지 않는다**. 5연승이면 은 2쯤, 5연패면 녹쇠 1.
- **시즌:** 2026-11-23을 시작으로 42일(6주)마다 한 시즌(`League.season_of`). 시즌이 바뀌면(마을 결투 창을 열 때·판이 끝날 때·시작 화면) 배치를 마친 사람은 **3단계 내려가고**(RR 0, MMR도 그만큼 깎음) **지난 시즌 최고 걸음이 칭호**로 남는다(`Meta.league_titles`, 시즌 번호 글 → 걸음). 언덕의 검이었으면 칭호도 "언덕의 검". 칭호는 가장 높은 하나를 "「S1 백금 2」 닉네임"으로 이름 옆에(결투 막대, 리그 창) 보인다. 배치도 못 마친 사람은 칭호·내려앉음이 없다.
- **무엇이 랭크에 세어지나:** 오직 **온라인 랭크 결투**. 같은 PC 결투와 보통 온라인 결투는 `Meta.record_duel`만 부르고 리그는 건드리지 않는다(테스트가 본다).
- **자격:** 로그인한 계정만 랭크를 한다(`League.can_play`: 게스트·로그인 안 함은 막힘, 창에도 한 줄). 관리자(`Account.is_admin()`)는 로컬에서 랭크를 해 볼 수 있지만 **순위표에는 절대 올리지 않는다**(`League.may_submit`).

## 매칭 (가장 단순하게)

기존 매칭을 그대로 쓰되 방 꼬리표 `mode`만 다르다(`DuelData.net_tag_ranked = "ranked"`): 랭크를 찾는 사람끼리만 모이고 보통 결투와 섞이지 않는다. **MMR로 짝짓지 않는다** — 랭크를 찾는 아무나. 락스텝 프로토콜(HELLO)을 바꾸지 않으려고 상대의 MMR·티어도 주고받지 않아서, MMR은 상대 기준이 아니라 "내 걸음의 기준값" 기준으로 움직인다. 사람이 늘면 HELLO에 걸음을 담아 MMR 근처끼리 모으는 것이 다음 단계.

## 나감·끊김·어긋남

- **내가 도중에 나감(Esc 포함):** 진 것으로 센다(`duel.gd _leave`).
- **게임이 꺼짐:** 랭크 결투를 시작할 때 `Meta.league.pending`을 저장해 두고(`League.begin_match`), 결과를 세거나 무효가 되면 지운다. 남아 있으면 다음에 마을 결투 창을 열 때 진 것으로 센다(`League.settle_pending`, 창에 한 줄 알림).
- **상대가 나감(`peer_lost("left")`):** 나간 쪽이 진 것이니 내가 이긴 것으로 센다.
- **시간 초과·버전 다름:** 누가 끊었는지 알 수 없으니 **무효**(RR 변화 없음). 내 선을 뽑아 이기는 일을 막으려는 것.
- **desync(`Lockstep.desync`):** 무효, RR 변화 없음. **비긴 결투**도 무효.

## 저장과 순위표

- `Meta`(저장, 옛 저장은 빈 값 → 처음 상태): `league`(season, step, rr, mmr, games, shield, peak, wins, losses, pending), `league_titles`, `league_offset`(관리자 시즌 수), `league_last`(마지막 결과), `league_sword`.
- **순위표** `LeagueBoard`(scripts/net/league_board.gd): GD-Sync 순위표 **`league_s<시즌>`**에 점수 `걸음 × 100000 + RR`(Data에 이름·걸음·RR·칭호)을 올리고, 위쪽 100명을 받는다. FallenShare처럼 `FallenShare._boot`로 노드를 올리지만 계정은 이미 로그인한 진짜 계정을 쓴다(자동 계정을 만들지 않는다). 판이 끝날 때마다 올리고(기다리지 않는다), 리그 창을 열 때 받는다. 받은 줄에서 내 이름·점수가 위쪽 100명 안이고 불멸 3이면 `league_sword`가 켜진다. 실패는 모두 조용히 한 줄. **대시보드에서 해 줄 일:** 시즌마다 순위표 `league_s<번호>`(점수 큰 것이 위)를 만든다(지금 시즌은 `League.board_name(League.season_now(meta))`). 키가 없는 PC·헤드리스에서는 창에 "GD-Sync 키가 필요하다"만 나온다. 실제 접속은 클라우드에서 못 해 보았다.
- 같은 이름의 사람이 둘이면 "내 줄"을 이름+점수로 찾아 틀릴 수 있다(가장 단순하게 정한 것).

## 화면 (UiKit, 그림이 먼저)

- **문장 아홉**(`assets/ui/league/tier_0~8.svg`, 생성기 `scripts/debug/build_league_emblems.gd`): 놋쇠 테두리와 가운데 검은 같고, 바깥 모양과 색이 티어마다 다르다 — 녹쇠 마름모, 청동 육각형, 은 팔각형, 금 방패, 백금 오각형, 금강 길쭉한 보석, 승천 날개, 불멸 가시 별, 언덕의 검 왕관. 아래 점은 티어 번호만큼.
- `LeagueUi.card`: 문장 + 티어·단계 + RR 막대(배치 중이면 배치 줄) + 칭호. 마을 결투 말뚝 창, 랭크 찾기 창, 시작 화면 왼쪽 위(로그인한 계정만)에 있다.
- **마을 결투 창:** "모르는 사람과 겨루기" 옆에 **"랭크 결투"**, 그 아래 "리그 보기"(`LeagueWindow`). 시작 화면 메뉴에도 "리그".
- `LeagueWindow`: 내 카드, 시즌과 남은 날, 이번 시즌 최고, 랭크 기록, 지난 칭호, 위쪽 N명(10줄, 온라인 순위표가 있을 때). 100명까지 받지만 10줄만 보인다(`list_rows`).
- **랭크 결과**(`LeagueResult`, 결투 결과 창 안): 문장·막대·RR이 처음 값에서 나중 값까지 세어 오르내린다(한 숫자 `걸음 × 100 + RR`을 움직이며 티어·단계를 다시 읽는다). 승급은 금빛, 강등은 붉은 번쩍임, 강등 보호는 "강등 보호 (RR 0)", 배치 중에는 "배치 n/5", 배치가 끝나면 정해진 티어.
- 캡처: `scripts/debug/shots/shot_league.gd` → `/home/claude/shots/league_window.png`, `league_result.png`, `league_emblems.png`.

## 관리 콘솔 (관리자 계정, 어디서나)

- `리그 <티어> <단계> <RR>` — 예: `리그 불멸 3 40`. 배치를 마친 것으로 하고 걸음·RR·MMR(그 걸음의 기준값)을 정한다. 단계·RR은 한계로 자른다(불멸 3만 RR이 100을 넘길 수 있다). `리그 언덕의검`은 표시를 켜고 `리그 처음`은 배치부터 다시.
- `시즌 다음` — 시즌 번호를 하나 올려 칭호와 3단계 내려앉음을 바로 본다.

## 시험(`tests/league_tests.gd`)

RR 증감 한계와 MMR 영향, 배치(5연승·5연패·금 1 상한), 승급·강등·강등 보호·녹쇠 1 바닥·불멸 3 쌓임, 언덕의 검 순위 100, 시즌 번호·소프트 리셋·칭호·언덕의 검 칭호, 게스트·관리자 제외, 같은 PC 결투는 안 셈, 저장 읽기와 옛 저장, 끝나기 전 종료(pending)와 무효, 순위표 줄, 관리 명령, 결과 판의 숫자·티어 글. 네트워크와 실제 저장 파일은 쓰지 않는다.

## 정한 것 (사용자가 바꿀 수 있다)

- 상대 MMR을 모르니 MMR 매칭을 하지 않고 한 줄로 아무나 맞붙인다.
- 언덕의 검 자격은 순위표 위쪽 100명 + 불멸 3(오프라인에서는 켜지지 않는다). 순위표 점수가 걸음 먼저, 같으면 RR.
- 시즌 3단계 내려앉기는 배치를 마친 사람만, 다시 배치하지 않는다.
- 관리자는 랭크를 로컬에서 해 볼 수 있다(순위표에만 안 올린다). 게스트는 못 한다.
- 결투 시간 초과는 무효(내 쪽 연결이 끊긴 것과 구별할 수 없어서).
- 랭크 보상 없음(기록과 칭호뿐), 결투 규칙·수치는 그대로.
- 아직 안 한 것: 실제 GD-Sync 순위표 접속 확인, 상대 걸음 교환과 MMR 근처 매칭, 다시 맞붙기.
