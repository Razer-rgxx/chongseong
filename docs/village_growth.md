# 마을 키우기 (2026-11-21 계획)

사용자: "다음 단계로 나아가고 마을을 키우는 느낌의 비중을 지금 10%라면 70%까지."
고른 것: 건물과 주민 둘 다 · 재료는 나무·돌·쇠 따로 · 마을 단계가 오르면 새 지역·구역과 새 검·기술이 열린다.

## 한 바퀴

1. 언덕 판·들판에서 싸우며 **나무·돌·쇠**를 모은다(조각은 그대로 검집·검 강화에 쓴다).
2. 마을 **빈 터**에 건물을 짓는다. 지으면 진짜 집이 한 조각씩 올라간다(검 보관집과 같은 방식).
3. 집이 생기면 들판에서 구한 **주민**이 들어와 산다. 주민에게 일을 맡기면 판이 끝날 때마다 재료를 모아 둔다.
4. 건물 수가 차면 **마을 단계**가 오른다: 개척지 → 마을 → 읍 → 성읍. 울타리가 돌담·성벽으로 바뀌고 불빛과 사람이 는다.
5. 단계가 오르면 **새 지역·구역**(들판의 닫힌 길, 언덕의 다음 구역)과 **새 검 모양·기술**(대장간·수련장)이 열린다.

## 재료가 나오는 곳

| 재료 | 들판 | 언덕 판 | 주민 일 |
|---|---|---|---|
| 나무 | 쓰러진 나무·그루터기(E로 벤다) | 낮마다 조금 | 나무꾼 |
| 돌 | 바위·무너진 담(E로 깬다) | 구역을 넘길 때 | 석수 |
| 쇠 | 옛 싸움터의 녹슨 칼·무덤 | 정예·우두머리 | 대장장이 |

## 건물(빈 터 8곳)

| 건물 | 재료 | 하는 일 |
|---|---|---|
| 검 보관집 | (있음) | 검집 → 검 칸 |
| 오두막 | 나무 | 주민 둘이 산다 |
| 나무꾼 움막 | 나무·돌 | 판마다 나무, 나무꾼 일자리 |
| 석공 마당 | 나무·돌 | 판마다 돌, 석수 일자리 |
| 풀무간 | 돌·쇠 | 대장장이 일자리, 대장간에 새 검 모양 |
| 망루 | 나무·돌 | 들판 지도가 넓어지고 닫힌 길 하나가 열린다 |
| 수련장 넓히기 | 나무·쇠 | 새 기술(움직임) |
| 돌담 | 돌 | 마을 단계 조건, 울타리가 돌담으로 |

## 만드는 순서

1. [x] 재료 세 가지(Meta 저장), 들판에서 E로 줍기, 판 끝 보상, 화면 오른쪽 아래 재료 표시.
2. [x] 빈 터 일반화(`Plot` → `StorageHouse`·`BuildingPlot`, 건물 데이터 `data/buildings/*.tres`), 동쪽 바깥 터(칸 34~50, 목책 문과 흙길), 오두막·나무꾼 움막·석공 마당.
3. [x] 주민: 들판 무리에 잡힌 사람(판마다 2곳)을 무리를 쓰러뜨린 뒤 풀어 주면 오두막에 산다(집이 없거나 차면 못 풀어 준다), 일터(나무꾼 움막·석공 마당, 자리 2)에 두면 판마다 +2.
4. [x] 마을 단계(건물 2·5·7, 사는 사람 1·3·6, 성읍은 돌담)와 겉모습: 바깥 터와 광장 길가 등불(2·4·6), 걷는 사람(2·4·6), 돌담을 지으면 목책이 가라앉고 돌담이 한 조각씩 놓인다. 작은 집·긴 집(마을부터)·돌담(읍부터). 촌장이 지금 단계와 모자란 것을 말한다.
5. [x] 열리는 것: 망루(마을부터) → 까마귀 고개로 가는 막힌 길 둘을 치운다, 마을 단계 → 언덕을 3·5·7구역부터 오를 수 있다(들판 언덕길에서 고른다, 건너뛴 구역은 보상에 안 센다), 풀무간(마을부터) → 판을 시작할 때 빈 칸에 벼린 검(마을·읍 귀함, 성읍 전설).
6. [ ] 남은 것: 수련장 넓히기 → 새 기술, 건물 단계 올리기(같은 건물 2단계).

세계에는 글자를 띄우지 않는다. 화면에 보이는 것은 글로 되풀이하지 않는다.
